# Rule: Auto Git Push on Changes

Whenever any new code or documentation changes are made to this repository:
1. Ensure all tests and builds pass.
2. Automatically stage changed files (`git add .`).
3. Commit with a descriptive conventional commit message (`git commit -m "..."`).
4. Push directly to remote `origin main` (`https://github.com/Omb2121/AI-CarrerCoach.git`).
5. Verify clean working tree (`git status`).
